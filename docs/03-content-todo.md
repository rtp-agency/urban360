# Что нужно подставить перед публикацией

Сайт собран и работает, но намеренно **не готов к публикации**: все юридически значимые данные — заглушки с маркером `TODO`. Публикация с заглушкой в Impressum сама по себе является нарушением §5 DDG.

---

## 1. Данные фирмы — файл [src/content/site.config.ts](../src/content/site.config.ts)

Один файл, всё в нём. Больше нигде эти значения не дублируются.

| Поле | Что подставить |
|---|---|
| `site.url` | боевой домен, `https://...` без слэша в конце |
| `contact.street`, `postalCode`, `city` | реальный адрес, по которому можно вручить документы. Не абонентский ящик |
| `contact.phone` + `phoneHref` | телефон в человекочитаемом виде и в формате `tel:+49...` |
| `contact.email` | почта на своём домене |
| `contact.hours` | часы, которые реально соблюдаются |
| `contact.serviceArea` | город + радиус. От этого зависит локальное SEO |
| `legal.entityType` | `sole` / `ug` / `gmbh`. Управляет тем, какие строки появятся в Impressum |
| `legal.legalName` | полное наименование как в Gewerbeanmeldung |
| `legal.managingDirector` | только для UG/GmbH |
| `legal.registerCourt`, `registerNumber` | только при записи в Handelsregister |
| `legal.vatId` | USt-IdNr., если есть. **Steuernummer сюда не пишем** |
| `legal.smallBusiness` | `true` пока действует §19 UStG |
| `legal.chamber`, `professionalTitle` | Handwerkskammer и профессия — обязательны при записи в Anlage B. Если Gebäudereinigung в услугах нет, поставьте `chamber: ""` и блок исчезнет |
| `legal.dataProtectionAuthority` | надзорный орган своей земли, полное название и адрес |
| `legal.hostingProvider` | хостер из подписанного AV-Vertrag |
| `legal.lastReviewed` | дата проверки юртекстов юристом |

## 2. Флаги обещаний — тот же файл, блок `claims`

Каждый флаг управляет блоком на главной. Пока `false` — блок не отображается, и на сайте нет утверждения, которое нечем подтвердить.

- `liabilityInsurance` → включить после получения полиса Betriebshaftpflicht **с явно включённым Winterdienst**
- `keyLossCoverage` → включить, если в полисе есть Schlüsselverlustdeckung
- `chamberRegistered` → включить после записи в реестр Handwerkskammer
- `documentedVisits`, `fixedContact` → уже `true`, это организационные обещания, которые вы контролируете сами

## 3. Фотографии

Сейчас на сайте стоят **временные изображения, сгенерированные нейросетью** (Gemini 3 Pro Image), лежат в `public/images/`:

| Файл | Где | Формат |
|---|---|---|
| `hero-gebaeude.jpg` | главная, первый экран | 1600×2000 |
| `objektbetreuung-treppenhaus.jpg` | главная, карточка «Objektbetreuung» | 1800×1350 |
| `team-fahrzeug.jpg` | Über uns | 2400×1350 |

Кадры подобраны так, чтобы снять юридические риски: люди только со спины и мелко в кадре, лиц не видно, на технике нет надписей и читаемых номеров. Это важно — **выдавать сгенерированных людей за свою бригаду нельзя**, это вводящая в заблуждение реклама по §5 UWG, ровно как выдуманные отзывы.

### Их всё равно нужно заменить

Генерация закрывает дыру в макете, но не продаёт. Перед выходом на реальных клиентов снимите свои объекты: ухоженный подъезд, который вы обслуживаете, работает лучше любой генерации, потому что его можно показать заказчику как референс.

Требования к своей съёмке (подробно в [02-rechts-checkliste.md](02-rechts-checkliste.md)):
- на людей — письменное согласие на публикацию, с правом отзыва
- на узнаваемые объекты — согласие собственника или управляющей компании
- на стоки — сохранённая лицензия и чек

Ещё нюанс: у изображений, созданных нейросетью без творческого вклада человека, в Германии **нет авторско-правовой охраны**. Юридически вам ничего не грозит, но и запретить конкуренту использовать ту же картинку вы не сможете. Собственная съёмка охраняется полностью.

Замена делается в одном месте: положить файл с тем же именем в `public/images/` и поправить `alt` в компоненте. Пропорции и позиционирование кадра уже настроены по брейкпоинтам, вёрстка не поедет.

Отдельно про `alt`: тексты пишутся описательно и **не должны содержать названий услуг из Anlage A**. Поисковики и палата читают alt так же, как обычный текст.

## 4. Доставка заявок с формы

Форма валидируется и защищена honeypot-полем, но **никуда не отправляет письма**, пока не задана переменная окружения:

```
CONTACT_WEBHOOK_URL=https://...
```

Эндпоинт должен принимать JSON `{name, company, email, phone, subject, message, locale}` и слать письмо на почту фирмы. Подойдёт любой SMTP-релей, n8n, Make или собственная функция. Пока переменная не задана, форма честно показывает ошибку, а не делает вид, что письмо ушло.

Скопируйте `.env.example` в `.env.local` и заполните.

## 5. Тексты, которые нужно вычитать вживую

- `src/content/copy.ts` — весь маркетинговый текст. Проверьте, что ни одно утверждение не выходит за рамки того, что фирма реально делает
- `src/content/services.ts` — список услуг. **Перед публикацией отправьте этот список в Handwerkskammer на письменное подтверждение** (`handwerksrechtliche Abgrenzung`, услуга бесплатная)
- `src/content/legal.ts` — Datenschutzerklärung, AGB, Widerrufsbelehrung. Тексты написаны по действующим нормам, но их обязан просмотреть юрист или профильный сервис. Ошибка в AGB стоит дороже проверки

## 6. Финальная проверка

Чеклист перед публикацией — в конце [02-rechts-checkliste.md](02-rechts-checkliste.md). Ключевое:

- [ ] Gewerbe зарегистрирован, все `TODO` заменены
- [ ] Поиск по проекту на строку `TODO` не даёт результатов
- [ ] AV-Vertrag с хостером подписан
- [ ] `CONTACT_WEBHOOK_URL` задан, тестовая заявка дошла
- [ ] HTTPS + редирект с http
- [ ] Ни одной услуги из Anlage A в текстах, заголовках, alt и meta
