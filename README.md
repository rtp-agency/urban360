# Urban360

Сайт фирмы бытовых и хозяйственных услуг в Германии: Hausmeisterservice, уборка, уход за территорией, зимняя служба, вывоз, технические работы.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:3000 -> редирект на /de
npm run build
npm start
```

Node 20+.

## Где что менять

Весь изменяемый контент лежит в `src/content/`. В компонентах текста нет.

```
src/content/site.config.ts   реквизиты, юрформа, флаги обещаний   <- главный файл
src/content/copy.ts          маркетинговые тексты DE/EN
src/content/services.ts      каталог услуг и сегменты клиентов
src/content/legal.ts         Datenschutz, AGB, Widerrufsbelehrung
```

`src/content/site.config.ts` содержит заглушки `TODO`. Пока они на месте, сайт публиковать нельзя: §5 DDG требует в Impressum реальные имя и адрес.

## Архитектура

- **Next.js 15 App Router**, TypeScript, Tailwind v4
- **Языки** через сегмент `[locale]`: `de` (по умолчанию) и `en`. Middleware добавляет префикс. Слаги маршрутов немецкие в обеих версиях, чтобы не плодить дубли в индексе
- **Статика**: все 19 страниц пререндерятся, JS на клиенте нужен только мобильному меню и форме

## Почему сайту не нужен cookie-баннер

Это не экономия, а осознанное архитектурное решение (обоснование в `docs/02`): §25 TDDDG требует согласия на любой доступ к устройству, не являющийся технически необходимым, а передача IP-адреса на чужой CDN — самая частая причина Abmahnung.

Поэтому на сайте:

- нет внешних шрифтов, используется системный стек (на устройствах Apple это SF Pro, установленный локально; отдавать SF Pro как веб-шрифт запрещает лицензия Apple)
- нет CDN, аналитики, пикселей, карт и встроенных видео
- нет cookie и нет доступа к localStorage
- CSP в `next.config.mjs` жёстко запрещает любые внешние запросы

Если позже понадобится аналитика — берите self-hosted Matomo без cookie либо готовьтесь ставить баннер и дополнять Datenschutzerklärung.

## Дизайн-система

Токены в `src/app/globals.css`, блок `@theme`.

- одна нейтральная палитра, один акцент (тёмно-зелёный), отдельный семантический цвет только для ошибок формы
- тёмная тема переключает те же переменные на `:root`, поэтому вся страница меняется целиком и ни одна секция не может «выпасть» в другую тему
- радиусы: поверхности 22px, поля ввода 14px, кнопки полностью скруглённые
- анимация появления сделана на CSS scroll-timeline. Видимое состояние — по умолчанию: без JS, в неподдерживающем браузере и при `prefers-reduced-motion` контент просто на месте

## Форма обратной связи

Server Action в `src/app/[locale]/kontakt/actions.ts`. Валидация на сервере, honeypot вместо стороннего CAPTCHA, никакого сохранения IP и User-Agent.

Отправка писем включается переменной `CONTACT_WEBHOOK_URL` (см. `.env.example`). Пока она пуста, форма показывает ошибку — намеренно, чтобы не сообщать пользователю об успехе, которого не было.
